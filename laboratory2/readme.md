Лабораторна робота №2
Тема. Моделювання нейронних мереж. Перцептрон Розенблата.
Мережі Хопфілда і Хемінга
Мета роботи: Ознайомитися з нейронними мережами Хопфілда і Хемінга.
Застосувати нейронні мережі до задачі розпізнавання образів.

Завдання 1
Реалізувати систему розпізнавання перцептронного типу для випадку
двох класів.
 Використовуючи основні можливості першої лабораторної роботи, створити
систему розпізнавання перцептронного типу з нормованими векторами ознак
числового типу. Система повинна забезпечити наступні дії:
1) Дозволяти послідовне введення з графічних файлів образів тестової
послідовності для двох класів та відображати їх у відповідному
графічному компоненті.
2) Створювати абсолютні та нормовані ознакові вектори для кожного зразка
навчальної послідовності з відображенням абсолютних та нормованих
ознакових значень.
3) Задавати початкове значення коефіцієнтів перцептрона Розенблата та
поточний крок навчання.
4) Обчислювати вихідний вектор та проводити класифікацію за поточним
станом перцептрона.
5) В режимі навчання з учителем підтвердити або спростувати результат
класифікації.
6) Провести корекцію ваг перцептрона та відобразити його стан після
корекції.
7) Оцінити збіжність процесу навчання.

Реалізація
Програма складається з чотирьох частин: навчальні зразки, параметри перцептрона, навчання з учителем та класифікація невідомого образу.
Зображення зразків завантажуються по одному, для кожного вибирається клас A або B. Для кожного зразка в таблиці показуються абсолютний і нормований вектори ознак. За замовчуванням на вхід перцептрона подається нормований вектор, але можна перемкнути на абсолютний.
Початкові ваги і поріг задаються випадковими числами від 0 до 1, крок навчання r вводиться вручну.
Вихід перцептрона рахується як сума добутків ваг на входи мінус поріг: якщо результат більший за 0, зразок відноситься до класу A, інакше до класу B.
У режимі навчання з учителем програма показує результат для кожного зразка, а користувач підтверджує його або спростовує. Якщо результат спростовано, ваги змінюються за формулою w(t+1) = w(t) + r * (d - y) * x, і на екрані видно ваги до та після корекції.
Збіжність оцінюється за графіком: по осі X номер епохи, по осі Y кількість помилок. Навчання завершене, коли в епосі помилок немає. Також можна запустити автонавчання і подивитись вихідний вектор для всієї вибірки.


Завдання 2
Розробити систему розпізнавання на базі штучної нейронної мережі Хопфілда
(та Хемінга) з наступними діями:
- введення зразкових зображень образів трьох класів та відображення у
відповідних графічних компонентах;
- обчислення абсолютних ознакових векторів та відображення ознакових
значень;
- для штучної нейронної мережі Хопфілда провести бінаризацію еталонних
ознакових векторів зі значеннями -1 та 1; для мережі Хеммінга провести
нормування ознакових еталонних векторів;
- обчислити матрицю коефіцієнтів ШНМ Хопфілда або вагові коефіцієнти
першого шару зв'язків у мережі Хеммінга. Відобразити відповідні матриці;
- ввести зображення невідомого вектора, обчислити його ознакові вектори
відповідно до типу мережі;
- провести класифікацію за методом Хопфілда або Хеммінга;
- проаналізувати процес класифікації.

Реалізація 
Програма складається з чотирьох частин: еталони, побудова мереж, невідомий образ та класифікація.
Еталони трьох класів завантажуються по одному, для кожного вводиться назва класу. У таблиці показуються абсолютні, нормовані та бінаризовані вектори (значення -1 або 1).
Для мережі Хопфілда матриця зв'язків рахується за еталонами, діагональ дорівнює нулю. Для мережі Хемінга ваги першого шару за замовчуванням дорівнюють x/2, поріг n/2 (біполярні вектори, як у методичці), а в другому шарі використовується параметр ε. Додатково можна перемкнутися на нормовані еталонні вектори. Матриці виводяться на екран.
Для невідомого образу будуються ті ж вектори, після чого його можна класифікувати обома мережами. Програма показує, як змінюється вихід на кожній ітерації, до якого еталона вийшло найближче і чи знайшла мережа відповідь.
Також виводяться таблиця відстаней між еталонами та діаграма виходів мережі Хемінга, щоб можна було порівняти результати двох мереж.

Вимоги для встановлення
Для запуску програм потрібні такі бібліотеки: `pip install bokeh numpy pillow`

Запуск програм
Кожне завдання знаходиться у своїй папці і запускається окремо. Спочатку перейдіть у папку першого завдання і запустіть додаток за допомогою команди bokeh serve:
`cd task1`
`py -m bokeh serve --show app.py`

Після завершення роботи зупиніть сервер (Ctrl+C), поверніться на рівень вище та перейдіть у папку другого завдання:
`cd ..`
`cd task2`
`py -m bokeh serve --show app.py`
де app.py — назва файлу з кодом у кожній папці.
