Система розпізнавання з навчанням 
Інтерактивний веб-додаток на Python з використанням бібліотеки Bokeh, призначений для створення системи розпізнавання з навчанням з нормованими векторами ознак числового типу.   

Основні можливості
Введення навчальної послідовності: послідовне введення серії образів навчальної послідовності для трьох класів та відображення їх у відповідному графічному компоненті.

Створення ознакових векторів: побудова абсолютних та нормованих ознакових векторів для кожного зразка навчальної послідовності з відображенням абсолютних та нормованих ознакових значень.
Кластеризація: проведення кластеризації поточного навчального зразка в режимі навчання з вчителем.
Статистична обробка: проведення поточної статистичної обробки кожного кластера за варіантом і відображення його поточних статистичних параметрів.
Введення невідомого образу: завантаження та відображення невідомого образу в графічному компоненті.
Аналіз ознак невідомого образу: обчислення абсолютного та нормованого вектора ознак для невідомого образу та відображення його ознакових значень.
Класифікація: проведення класифікації невідомого образу за його вектором ознак та вибраним методом класифікації.   

Варіанти кластерного аналізу обчислення геометричних центрів кластерів за математичним сподіванням векторів ознак навчальної послідовності у просторі та евклідової міри в декартовій системі координат (метод порівняння з еталоном).
Обчислення мінімальних та максимальних значень кожної компоненти кожного кластера у просторі ознак за зразками навчальних послідовностей (метод ортогональних областей) та перевірки належності до кожного кластера.   

Вимоги для встановлення
Для запуску програм потрібні такі бібліотеки: `pip install bokeh numpy pillow`

Запуск програми
Спочатку перейдіть у папку 3 завдання і запустіть додаток за допомогою команди bokeh serve:
`cd task1`
`py -m bokeh serve --show app.py`
де app.py — назва файлу з кодом у кожній папці.
