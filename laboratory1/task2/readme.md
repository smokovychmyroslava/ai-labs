Система розпізнавання
Інтерактивний веб-додаток на Python з використанням бібліотеки Bokeh, призначений для побудови абсолютних та нормованих векторів ознак за методом порівняння з еталоном для класифікації невідомих зображень.

Основні можливості
Введення еталонів: завантаження еталонних образів для трьох-чотирьох класів та відображення їх у графічних компонентах.
Створення еталонних векторів: побудова абсолютних та нормованих ознакових векторів для кожного еталону з виведенням абсолютних та нормованих значень.

Введення невідомого образу: завантаження зображення невідомого образу та його відображення у графічному компоненті.
Аналіз ознак: обчислення абсолютного та нормованого вектору ознак для невідомого образу з відображенням його ознакових значень.
Класифікація: обчислення міри відповідності невідомого образу до кожного еталону за варіантом норми та проведення класифікації.   
Варіанти норми:
Евклідова норма (евклідова відстань).
Норма Чебишева (чебишевська відстань).
Манхетенська норма (манхетенська відстань).  

Вимоги для встановлення
Для запуску програм потрібні такі бібліотеки: `pip install bokeh numpy pillow`

Запуск програми
Спочатку перейдіть у папку 2 завдання і запустіть додаток за допомогою команди bokeh serve:
`cd task2`
`py -m bokeh serve --show app.py`

Після завершення роботи зупиніть сервер (Ctrl+C), поверніться на рівень вище та перейдіть у папку наступного завдання:
`cd ..`

де app.py — назва файлу з кодом у кожній папці.
