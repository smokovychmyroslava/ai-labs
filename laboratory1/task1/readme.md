Вектор ознак зображення (Bokeh App)
Інтерактивний веб-додаток на Python з використанням бібліотеки Bokeh, призначений для побудови абсолютних та нормованих векторів ознак стандартизованих графічних зображень шляхом розбиття зображення на сітку.

Основні можливості
Завантаження зображень: Підтримка форматів bmp, png, jpg, jpeg.
Гнучке налаштування сітки: Визначення кількості рядків і стовпців для розбиття зображення на прямокутні області (наприклад, 4 на 5 = 20 зон).
Бінаризація та інверсія: Налаштування порогу бінаризації від 0 до 255 та опція інвертування для світлого штриха на темному тлі.

Візуалізація:
Відображення завантаженого зображення з накладеною червоною сіткою.
Гістограми абсолютного та нормованого векторів ознак.
Інтерактивна таблиця з детальною інформацією по кожній області сітки.

Вимоги для встановлення
Для запуску програм потрібні такі бібліотеки: `pip install bokeh numpy pillow`

Запуск програми
Спочатку перейдіть у папку 1 завдання і запустіть додаток за допомогою команди bokeh serve:
`cd task1`
`py -m bokeh serve --show app.py`

Після завершення роботи зупиніть сервер (Ctrl+C), поверніться на рівень вище та перейдіть у папку наступного завдання:
`cd ..`

де app.py — назва файлу з кодом у кожній папці.
